# SuRE paper codes
This is the master repository for all the codes in the SuRE MPRA paper. Each submodule in the repository is linked to the method or analysis done in the paper and could be referred as such.

- `EvaReg-analysis`: contains all the analysis/code related to EvaReg models
- `EvaReg-training`: contains all the code related to EvaReg model training
- `SuRE-gg-variants`: contains the code related to graphs and variant analysis
